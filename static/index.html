Tips & Notes
•Any data extracted by AI should always be human-verified before publication. AI can and does make mistakes — this tool is an assistant, not a replacement for expert review.
•Always do a test run on a small sample before the full extraction.
•Phrase questions assuming nothing, especially when screening. "If the PDF describes an intervention, list the target mechanisms used" is less prone to hallucination than "List the mechanisms used in the intervention."
•You can include URLs in the additional context field to help the AI — e.g. "Use the JBI guidelines at jbi.global/…/Checklist_for_RCTs.pdf when answering this item."

ⓘ Providers occasionally change their API request format. If AI runs start failing consistently, check your target model's API documentation, then try the JSON Mode tab to edit the raw request directly.
Edit the raw HTTP request sent to the AI API. Useful if a provider changes their request format. The response is still parsed for [[N]] answers, so your prompt must still ask for that format (it's included in {{PROMPT}}).
Placeholders (substituted at run time):
{{PROMPT}} — full assembled prompt (system context + codebook + PDF + questions + answer instruction)
{{PDF_TEXT}} — extracted PDF text only  ·  {{QUESTIONS}} — numbered question list
{{SYSTEM_CONTEXT}} — System Context box  ·  {{API_KEY}}  ·  {{MODEL}}
response_path — dotted path to the answer text in the reply (e.g. choices.0.message.content).
